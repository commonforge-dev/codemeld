# Contributing to codemeld

The most useful early contribution is a report of every command codemeld asked permission for
that you believe it should not have, plus any issues or errors you hit. Send it as a GitHub issue
using the bug template; what to include is described in the contributing guide.

### → [`contributing/`](contributing/README.md)

That page covers the report, setting up a dev environment, the rules any change must keep, and a
module-by-module tour of the code.

By contributing you agree that your contributions are licensed under the
project's [MIT License](LICENSE). Please also follow the
[Code of Conduct](CODE_OF_CONDUCT.md).

**Found a security issue?** Do not open a public issue — follow the private
disclosure path in [`SECURITY.md`](SECURITY.md).
